# 图示说明

用足以解释关键问题的最小视图，配上简短说明。按需选择一种或少数组合形式，不默认把所有形式都用一遍。

- 逻辑或算法：伪代码；运行时顺序：调用树或时序图。
- 界面结构或文件职责：浅层组件树、文件树，只保留相关状态和职责。
- 交互、控制流、数据流或状态变化：Mermaid。
- 重点是已有结构的变化：diff；缺少上下文会影响理解时，给出完整的相关结构。
- 布局或概念关系不适合上述形式时，创建聚焦单一问题的 HTML，沿用已有视觉风格，并检查桌面与移动端可读性。按用户指定位置保存，否则放在当前工作区，通过可用预览或文件链接交付。

项目图示必须基于读过的代码或资料；区分现状、拟议变化和示意数据，不把示例画成已实现结构。需要具体写法时读取 [形式示例](references/examples.md)。

# 来源说明

来源：`Java开发手册(黄山版).pdf`。

## 手册定位

《Java 开发手册》是 Java 社区爱好者的集体智慧结晶和经验总结，经历了多次大规模一线实战的检验及不断完善。

手册以 Java 开发者为中心视角，划分为七个维度：

1. 编程规约
2. 异常日志
3. 单元测试
4. 安全规约
5. MySQL 数据库
6. 工程结构
7. 设计规约

依据约束力强弱及故障敏感性，规约依次分为三大类：

- 【强制】
- 【推荐】
- 【参考】

延伸信息中：

- “说明”对规约做适当扩展和解释；
- “正例”提倡编码和实现方式；
- “反例”说明需要提防的雷区，以及真实的错误案例。

# Document Sync

用于检查实现或流程变化是否让 README、docs、示例、图示或博客说明失真。目标是保持文档与当前事实一致，不顺手重写无关内容。

## Process

1. 先确认本次事实变化：接口、配置、目录、职责、流程、术语、状态、示例或配图发生了什么改变。
2. 搜索直接引用这些事实的文档、示例、SVG/HTML、Mermaid、注释和说明文件。
3. 区分真正过时的内容与仍然成立的背景说明；只修改被当前变化影响的部分。
4. 对跨文件术语、链接、路径、命令和流程图做一致性检查，避免正文已更新但示例或配图仍保留旧说法。
5. 修改后再次搜索旧术语、旧路径或旧行为，并报告仍未能确认的文档范围。

## 边界

`document-sync` 以已确认的实现或规范事实为准，不负责创造新的需求或技术设计。没有证据表明文档过时时，不为了统一风格而改写内容。

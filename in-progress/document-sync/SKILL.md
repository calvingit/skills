# Document Sync

用于检查实现或流程变化后，README、项目文档、示例、图示、说明文件或其他相关资料是否仍与实际情况一致。目标是保持文档与当前事实同步，不顺手改写无关内容。

## 流程

1. 先确认本次发生变化的事实：接口、配置、目录、职责、流程、术语、状态、示例或配图具体发生了什么变化。
2. 搜索描述或依赖这些内容的项目文档、示例、SVG/HTML、Mermaid、注释和说明文件。
3. 区分真正过时的内容与仍然成立的背景说明；只修改受当前变化影响的部分。
4. 对跨文件术语、链接、路径、命令和流程图做一致性检查，避免正文已更新但示例或配图仍保留旧说法。
5. 修改后再次搜索旧术语、旧路径或旧行为，并报告仍无法确认是否需要更新的文档范围。

## 边界

`document-sync` 以已确认的实现或规范事实为准，不负责创造新的需求或技术设计。没有证据表明文档已经过时时，不为了统一风格而改写内容。
